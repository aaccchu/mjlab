# 机器人足球场 — 完整尺寸清单

> 本文档列出构建足球场虚拟平台所用的**全部尺寸信息**(单位:米)。
> 这些值是 `SoccerFieldCfg` 的默认参数,见
> [src/mjlab/terrains/soccer_field.py](../../src/mjlab/terrains/soccer_field.py)。
> 渲染效果图见本目录下的 `soccer_topdown.png` / `soccer_persp.png` / `soccer_field_schematic.png`,
> 导出的 MuJoCo 场景见 `soccer_field.xml`。

---

## 一、坐标系约定

| 项 | 值 |
|---|---|
| 原点 | 场地几何中心 (0, 0, 0) |
| 单位 | 米 (m) |
| x 轴 | 长度方向(左→右) |
| y 轴 | 宽度方向(下→上) |
| z 轴 | 竖直向上 |
| 尺寸基准 | **所有尺寸以线的外边缘为准** |

---

## 二、配置参数(SoccerFieldCfg 默认值)

| 参数名 | 值 (m) | 含义 |
|---|---|---|
| `half_length` | 11.0 | 半长 L/2,x∈[-11, 11] |
| `half_width` | 7.0 | 半宽 W/2,y∈[-7, 7] |
| `line_width` | 0.125 | 线宽 t |
| `center_circle_radius` | 2.0 | 中圈半径 R_c(到线中心) |
| `center_mark_radius` | 0.0625 | 中心点半径 |
| `goal_area_depth` | 0.75 | 小禁区深度 |
| `goal_area_half_width` | 1.95 | 小禁区半宽 |
| `penalty_area_depth` | 2.25 | 大禁区深度 |
| `penalty_area_half_width` | 3.45 | 大禁区半宽 |
| `penalty_mark_dist` | 7.4 | 罚球点到球门线的距离(|x|) |
| `penalty_mark_radius` | 0.10 | 罚球点半径 |
| `corner_arc_radius` | 1.0 | 角球弧半径 |
| `goal_inner_half_width` | 1.0 | 球门内侧半宽,开口 y∈[-1, 1] |
| `goal_height` | 1.0 | 球门内高,开口 z∈[0, 1] |
| `goal_depth` | 0.5 | 球门深度(向场外) |
| `goal_post_radius` | 0.05 | 立柱/横梁半径(直径 0.10) |
| `circle_segments` | 64 | 中圈分段数(box 拼接) |
| `arc_segments` | 16 | 角球弧分段数(box 拼接) |

派生量:
- 场地总长 = 2 × 11.0 = **22.0 m**
- 场地总宽 = 2 × 7.0 = **14.0 m**
- 半线宽 t/2 = **0.0625 m**

## 五、禁区(右侧;左侧 x→-x 镜像)

### 小禁区(球门区)
- 外边界:x∈[10.25, 11.0],y∈[-1.95, 1.95]
- 前线(box):中心 (10.1875, 0),半尺寸 (0.0625, 2.0125)
- 上下边线(box ×2):中心 (10.5625, ±1.95),半尺寸 (0.4375, 0.0625)

### 大禁区(罚球区)
- 外边界:x∈[8.75, 11.0],y∈[-3.45, 3.45]
- 前线(box):中心 (8.6875, 0),半尺寸 (0.0625, 3.5125)
- 上下边线(box ×2):中心 (9.8125, ±3.45),半尺寸 (1.1875, 0.0625)

> 禁区为三面线框,开口朝球门线(x=11)。前线半宽含 ±t/2 扩展,与上下边线对齐。

## 七、球门(3D,有碰撞)

> 右球门门线 x=+11,左球门门线 x=-11(镜像)。立柱/横梁为 cylinder,**有碰撞**(contype=1, conaffinity=1, condim=3);球网为半透明 box,**无碰撞**。

### 内部净尺寸(每侧)
| 项 | 值 |
|---|---|
| 内宽(开口 y) | [-1.0, 1.0],净宽 2.0 m |
| 内高(开口 z) | [0, 1.0],净高 1.0 m |
| 深度 | 0.5 m(向场外) |
| 立柱/横梁直径 | 0.10 m(半径 0.05) |

### 球门几何元素(以右球门为例,门线 gl=11.0,后平面 back=11.5)
| 元素 | 几何 | 数量 | 位置示例 | 朝向 |
|---|---|---|---|---|
| 前立柱 | cylinder | 2 | (11.0, ±1.0),z 0→1,半长 0.5 | 竖直 |
| 后立柱 | cylinder | 2 | (11.5, ±1.0),z 0→1,半长 0.5 | 竖直 |
| 前横梁 | cylinder | 1 | (11.0, 0, 1.0),半长 1.0 | 沿 y |
| 后横梁 | cylinder | 1 | (11.5, 0, 1.0),半长 1.0 | 沿 y |
| 顶部侧梁 | cylinder | 2 | (11.25, ±1.0, 1.0),半长 0.25 | 沿 x |
| 后网 | box | 1 | (11.45, 0, 0.5),半尺寸 (0.005, 1.0, 0.5) | 视觉,无碰撞 |
| 顶网 | box | 1 | (11.25, 0, 1.0),半尺寸 (0.25, 1.0, 0.005) | 视觉,无碰撞 |
| 侧网 | box | 2 | (11.25, ±1.0, 0.5),半尺寸 (0.25, 0.005, 0.5) | 视觉,无碰撞 |

> 每侧球门 = 4 立柱 + 2 横梁 + 2 侧梁 = **8 个碰撞 cylinder**,两侧共 16 个;球网每侧 4 块,两侧共 8 块(无碰撞)。

## 十、几何统计

- 场地几何总 geom 数:**173**(独立测试编译)
  - 1 场地 + 4 边线 + 1 中线 + 1 中心点 + 64 中圈段 + 4×16 角球弧段 + 罚球点/禁区线 + 16 球门碰撞体 + 8 球网
- 球门碰撞体:16 个(全部 contype/conaffinity ≠ 0)
